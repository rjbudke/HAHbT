# HAHbT
Home Assistant Habit Tracker

Home Assistant Habit Tracker was created to fulfill my needs of having a habit tracker that integrated seamlessly into Home Assistant. I wanted to have real world automations and actions based on my habits, that way if I needed a nudge to mow the lawn because it's been longer than normal, I could. If I wanted to get a reminder two weeks before I usually get my haircut, I could do that. If I wanted to track the last time I had pizza from my favorite pizza place, I could do that too.

HAHbT is built within Home Assistant to be scalable, versatile, and personal.
